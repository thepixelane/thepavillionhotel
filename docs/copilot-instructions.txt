# Project Instructions

## Project Overview

Project Name: The Pavillion Hotel Website

This is a premium hotel marketing website built using Next.js 15. The objective is to create a fast, modern, elegant, SEO-friendly experience that encourages direct bookings and event enquiries.

This is NOT an e-commerce platform or booking application.

The actual booking process is handled by an external PMS/Booking Engine (STAAH / AxisRooms). Our application is responsible only for presenting hotel information, collecting enquiries, and redirecting users to the booking engine.

# Development Principles

Always prefer:

- Server Components whenever possible
- Client Components only when interaction is required
- Type-safe code
- Reusable components
- Clean architecture
- Mobile-first development
- Accessibility
- Performance over unnecessary animations

Avoid:

- Large client-side bundles
- Heavy third-party libraries
- Inline styles
- Hardcoded content
- Duplicate components
- Business logic inside UI components

# Data

All editable content must come from Sanity CMS.

Never hardcode

- Room names
- Descriptions
- Amenities
- Images
- Contact details
- Social links
- Gallery items

Temporary placeholder content is acceptable during development but must be easy to replace.

---

# Images

Always use

Next.js Image component

Images should

- Lazy load
- Use WebP
- Use AVIF where available
- Preserve aspect ratio

Never use HTML img tags unless absolutely necessary.

---

# Animations

Animations should be subtle.

Allowed

- Fade
- Slide
- Small scale
- Hover transitions

Avoid

- Long animations
- Heavy parallax
- Auto-playing effects
- Large videos

Performance always takes priority.

---

# Forms

Forms must

- Use React Hook Form
- Validate using Zod
- Be reusable

Create generic form components whenever possible.

---

# Booking Integration

Do NOT build booking functionality.

Booking flow:

Website

↓

Generate booking URL

↓

Redirect user

↓

External PMS completes booking

Never embed booking pages inside iframes.

# Placeholder Content

Until client assets are received:

Use

- Lorem Ipsum
- Placeholder hotel images
- Dummy room information
- Temporary logo

Build layouts to make replacement easy without changing code.

Do not tightly couple layouts to placeholder assets.
